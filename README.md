> **Version Prototype**

## AxiomBot

AxiomBot est actuellement disponible sur Discord et propose notamment :

* 👥 Gestion des rôles
* 🏠 Gestion des salons
* 🛡️ Modération
* 🔊 Gestion des salons vocaux
* 🎫 Système de tickets

## Écosystème Axiom

Le projet est conçu pour pouvoir évoluer vers plusieurs plateformes et services :

* 💬 Discord
* ✈️ Telegram
* 🌐 Web
* 🔗 APIs et services externes
* ☁️ Services de stockage
* ▶️ Intégrations avec différentes plateformes

À terme, les différentes instances d'Axiom pourront également communiquer entre elles afin de partager des services, des données ou certaines tâches.

## Architecture

Axiom est conçu avec une architecture modulaire afin de permettre l'ajout de nouvelles fonctionnalités et de nouvelles plateformes sans devoir reconstruire l'ensemble du projet.

## Contribution

Axiom est un projet évolutif.

Les nouvelles fonctionnalités, intégrations, améliorations et idées sont les bienvenues.
